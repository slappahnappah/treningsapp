# Treningsapp

En personlig app for styrketrening og calisthenics: rask logging under økta, historikk, rekorder og en regelbasert progresjonsmotor. Webapp (PWA) for iPhone først, bygget slik at en native app kan komme senere.

## Status

Planleggingen er ferdig, og selve appen er ikke bygget ennå.

## Dokumenter

- [Byggebrief](docs/byggebrief.md): funksjoner, datamodell, progresjonsmotor, arkitektur og byggerekkefølge. Start her.

## Planlagt struktur

```
apps/web        React + TypeScript, PWA
apps/mobile     Expo / React Native (senere)
packages/core   Ren TypeScript: datamodell, formler, progresjonsmotor
```
